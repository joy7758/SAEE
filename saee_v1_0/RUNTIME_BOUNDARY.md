# Runtime Boundary

## Core Runtime

The v1.0 core runtime is only:

```text
Sense -> Mutate -> Evaluate -> Select -> Lineage -> Update
```

The runtime imports only `saee_v1_0.kernel.*` modules.

## Side Layers

The following are side-layer or archive references only:

- v0.6 observability;
- v0.7 reflexivity;
- v0.8 identity stability;
- Phase II behavior science;
- v0.4 phase transition;
- v0.5 generated evolution physics.

They are not imported by the v1.0 runtime.

## Forbidden in Runtime

- phase theory systems;
- generated physics abstractions;
- observer-in-the-loop systems;
- epistemic or semantic selection systems;
- self-generated fitness;
- hypergraph lineage;
- behavior-science feedback.
