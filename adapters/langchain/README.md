# LangChain + SAEE Adapter Template

LangChain officially exposes MCP tools through `langchain-mcp-adapters` and
`MultiServerMCPClient`. `mcp-config.json` is the configuration object to pass to
that client after replacing `${SAEE_REPO}` with an absolute repository path.

Official reference: <https://docs.langchain.com/oss/python/langchain/mcp>

This repository does not install or execute LangChain for this adapter. The
template is reviewed machine configuration, not interoperability or adoption
evidence.
