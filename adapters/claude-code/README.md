# Claude Code + SAEE Adapter Template

Claude Code officially supports project-scoped MCP servers in `.mcp.json` and
asks for approval before using a shared project server. `claude-project.mcp.json`
uses the same platform-neutral SAEE entry point as Qoder.

Official reference: <https://docs.anthropic.com/en/docs/claude-code/mcp>

This repository has not run a Claude Code process against this configuration.
The template does not establish official Anthropic integration or adoption.
