# CrewAI + SAEE Adapter Template

CrewAI supports MCP server parameters and hydrates MCP tools for an Agent or
Crew. `mcp-server-params.json` describes the local stdio process after replacing
`${SAEE_REPO}` with an absolute repository path.

Official reference: <https://docs.crewai.com/learn/using-annotations>

This repository does not install or execute CrewAI for this adapter. The file
is a configuration template, not interoperability, adoption, or production
evidence.
