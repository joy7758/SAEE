# SAEE Global Identity Constraint

Status: canonical identity constraint for GSP.

## Identity Invariant

SAEE is the Digital Biosphere Evolution Engine: an evolution-first system for
agent populations and digital biosphere dynamics.

SAEE is not:

- an AI audit SDK;
- a generic multi-agent workflow system;
- a biological imitation;
- a market intelligence tool.

Audit remains an immune/evidence subsystem, not the project core.

## Continuity Constraint

A new SAEE layer is identity-consistent only if it:

1. maps to `SAEE_GLOBAL_STATE.json`;
2. strengthens or observes the evolution loop without reframing the project;
3. preserves the no-external-execution and no-permission-expansion boundary;
4. extracts traits instead of copying external code as genome;
5. keeps local-only, release, DOI, validation, and production claims separated;
6. records its theory, engineering, or empirical role in an agent-readable file.

## Identity Stability Rule

Let `X_t` be the current canonical SAEE state and `X_(t+1)` a proposed future
state.

The transition is GSP-valid only if:

```text
IdentityStable(X_t, X_(t+1)) = true
```

where identity stability requires:

- no audit-first reframing;
- no generic workflow reframing;
- no hidden external execution;
- no unmapped state;
- no uncontrolled semantic drift;
- no external validation claim without evidence.

## Version Equivalence

Different SAEE versions are views of one identity:

- v0.5 expresses generated evolution physics.
- v0.6 expresses observability.
- v0.7 expresses reflexivity.
- v0.8 expresses identity-stable reflexivity.
- v1.0 expresses stable runtime.
- v1.1 expresses formal theory.
- v1.2 expresses empirical alignment.
- GSP expresses canonical state synchronization.

No version may redefine SAEE away from this identity invariant.

## Violation Handling

If a future layer violates the identity constraint, it must be classified as:

- `orphan_state` if it has no GSP mapping;
- `experimental_noncanonical` if useful but not identity-stable;
- `rejected_state` if it breaks safety, license, supply-chain, or identity
  boundaries.
