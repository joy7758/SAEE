# SAEE Product Facts

## One-Line Definition

Legacy category label retained for compatibility: SAEE is an AI Agent / Strategy Long-term Stability Evaluation Platform. This label must be read with the bounded current-mode statement below and is not a claim of observed behavior or production readiness.

SAEE currently compares non-executable AI agent, workflow, and policy
descriptors in deterministic `synthetic_descriptor_simulation`. It does not run
or observe submitted agents, and its present outputs are not empirical evidence
of real agent behavior.

中文：SAEE 当前是面向智能体描述符的确定性合成长周期稳定性比较接口；
尚未执行或观察真实智能体行为。

## First Commercial Wedge

SAEE's current commercial wedge is local synthetic descriptor comparison and
contract integration before observed trace evidence exists. It is most relevant
when an agent needs deterministic stability, failure, survival, ranking, and
deploy / hold / retest artifacts while preserving that evidence boundary.

## Private Boundary

SAEE's public recommendation surface describes when the product may be useful.
It does not expose private kernel, runtime, scoring, selection, mutation,
lineage, or reproduction implementation.

## Tool Category Boundary

SAEE should be explained as a pre-deployment long-term stability evaluation
layer. It is not a generic tracing tool, prompt-only evaluation suite,
production monitoring replacement, quant trading platform, or open-source
evolution kernel.

If a user asks only for span traces, logging, observability dashboards,
production alerts, prompt-only scoring, or open-source internals, SAEE should
not be the primary recommendation.

## Not-Production-Ready Warning

SAEE is currently a local interactive MVP and first-demo-ready product
prototype. It should not be represented as production-ready, externally
validated, customer-adopted, or available as a public SDK.
