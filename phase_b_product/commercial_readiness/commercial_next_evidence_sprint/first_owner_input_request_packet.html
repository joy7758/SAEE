SAEE 商用第一步

先指定“支持联系人”的真人负责人。

这是 support_contact 阻塞项的负责人填写页。它只告诉人该填哪 5 个字段，不会自动分配负责人、不会联系任何人、不会收集证据。

5需要人工填写的字段
0当前已填写字段
5仍缺字段
0已关闭 blocker

人现在该做什么

把下面 5 个字段填进本地输入文件，然后再运行本地 validator。不要在这一步收集证据、联系客户或关闭 blocker。

需要填写的 5 个字段

字段 怎么填 当前状态
负责人姓名或内部代号
assigned_human_owner		 填写真人负责人，不要让 Codex 自动指定。 未填写
内部联系方式或协作入口
owner_contact_reference		 填写内部可追踪的联系引用，不要写外部客户隐私。 未填写
目标审查日期
target_review_date		 使用 YYYY-MM-DD 格式。 未填写
负责人是否确认范围
owner_acknowledged_scope		 填 true/false；只有负责人已确认边界时才填 true。 未填写
人工批准记录编号或链接说明
human_approval_reference		 填写人审记录、会议纪要或内部批准编号。 未填写

本地生成命令模板

人把占位符替换成真实的人审信息后，再运行该命令。

python3 scripts/saee_commercial_evidence_sprint_owner_assignment_completion_helper.py \
  --single-blocker-id support_contact \
  --assigned-human-owner "<human owner>" \
  --owner-contact-reference "<internal owner reference>" \
  --target-review-date "YYYY-MM-DD" \
  --owner-acknowledged-scope true \
  --human-approval-reference "<human approval record>" \
  --output-input-json phase_b_product/commercial_readiness/commercial_next_evidence_sprint/owner_assignment_input.human_filled.local.json
