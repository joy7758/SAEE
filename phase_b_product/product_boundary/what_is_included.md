# What Is Included

Status: Phase B public product boundary.

The productization package includes:

- conceptual client API documentation;
- usage examples at abstraction level;
- public request and response object descriptions;
- platform overview;
- capability map;
- integration guide;
- product boundary and security model.

The included material is designed to make SAEE understandable and usable as an
abstraction without exposing private implementation logic.
