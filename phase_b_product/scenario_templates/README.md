# SAEE Scenario Template Layer v1.0

This directory contains industry-specific scenario templates for the SAEE
product experience layer.

It helps a user start from a plain decision scenario:

1. Choose scenario
2. Input 3 candidates
3. Generate evaluation scenario
4. Run the existing SAEE decision loop
5. Show a decision report

This layer does not modify SAEE core algorithms, runtime, backend decision
logic, scoring formulas, API schema, or private implementation.

## Supported Scenarios

1. AI Agent Deployment
2. Customer Service AI
3. Sales Agent
4. Commercial Design
5. Business Strategy

## Boundary

Scenario templates are domain-specific input wrappers only. They do not claim
production readiness, customer validation, external validation, or public SDK
availability.
