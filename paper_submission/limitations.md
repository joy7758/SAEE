# Limitations

## Empirical Boundary

The evidence is local and observational. The object is frozen for scientific
description.

## System Boundary

The kernel is fixed and minimal. It is not changed by this paper package.

## Claim Boundary

This paper does not claim:

- open-ended evolution under current constraints;
- external validation;
- universal law status;
- production deployment;
- benchmark superiority;
- public implementation release.

## Disclosure Boundary

The paper does not disclose:

- code;
- runtime logic;
- kernel structure;
- mutation algorithms;
- selection algorithms;
- fitness implementation;
- lineage implementation;
- reproduction implementation.
