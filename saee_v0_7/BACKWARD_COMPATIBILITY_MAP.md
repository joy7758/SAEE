# Backward Compatibility Map

## v0.6 to v0.7

| v0.6 surface | v0.7 compatibility |
| --- | --- |
| Observation events | Used as causal feedback sources through meaning feedback. |
| Rule genesis tracker | Preserved inside observer-in-the-loop system. |
| Fitness explanations | Converted into epistemic fitness and interpretation pressure. |
| Semantic lineage graph | Preserved as observer output and extended with explanation-influenced DAG. |
| Self-description generator | Used to produce next-generation meaning feedback. |
| Counter-observer loop | Embedded into the evolution runtime. |

## v0.5 to v0.7

| v0.5 surface | v0.7 compatibility |
| --- | --- |
| Generated physics components | Reused locally; v0.7 changes pressure, not external permissions. |
| Generated fitness function | Used as base fitness before epistemic fitness. |
| Generated laws and dimensions | Still generated by v0.5 components. |
| Hypergraph lineage | Preserved as generated physics evidence. |

## Non-Breaking Policy

v0.7 is additive. Existing local commands remain valid:

```bash
python3 -m kernel.runtime --generations 3 --output-dir kernel/output/demo-run
python3 -m kernel_v0_2.runtime_v0_2 --generations 4 --output-dir kernel_v0_2/output/demo-run
python3 saee_v0_3/KERNEL_BOOTSTRAP_SCRIPT.py --generations 3 --output-dir saee_v0_3/output/demo-run
python3 saee_v0_4/KERNEL_BOOTSTRAP_SCRIPT.py --generations 5 --output-dir saee_v0_4/output/demo-run
python3 saee_v0_5/bootstrap/v0_5_bootstrap.py --generations 6 --output-dir saee_v0_5/output/demo-run
python3 saee_v0_6/bootstrap/v0_6_bootstrap.py --generations 6 --output-dir saee_v0_6/output/demo-run
```

New v0.7 command:

```bash
python3 saee_v0_7/bootstrap/v0_7_bootstrap.py --generations 6 --output-dir saee_v0_7/output/demo-run
```
