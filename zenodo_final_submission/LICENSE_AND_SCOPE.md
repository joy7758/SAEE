## License Status

Before Zenodo upload, a human must select a license for the academic text

## Suggested Scope

The Zenodo package should be treated as an academic text/data-description
package only.

It should not be treated as:

- source-code release;
- runtime release;
- software package;
- production system;
- externally validated benchmark;
- universal-law proof.

## Required Human Checks

Before upload:

1. Confirm author names and affiliations.
2. Confirm ORCID entries.
3. Select publication license.
4. Select Zenodo access right.
5. Confirm no institutional disclosure rule is violated.
6. Confirm no private implementation detail appears in the package.
7. Confirm DOI and upload state are not claimed before the actual external
   action occurs.
