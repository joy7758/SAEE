# Reproducibility Statement

Status: reproducible description, not public implementation release.

## What Is Reproducible

This package makes the public scientific description reproducible:

- the object definition;
- the aggregate observational results;
- the phase-space labels;
- the attractor interpretation;
- the invariant classifications;
- the candidate law statements and non-claims.

## What Is Not Included

This package does not include a runnable implementation. It excludes:

- code;
- runtime logic;
- kernel structure;
- mutation procedure;
- selection procedure;
- fitness computation;
- lineage construction;
- reproduction internals;
- private architecture details.

## Reason

The package is intended to publish the scientific object definition and
observational findings while preserving implementation confidentiality.

## Reproducibility Boundary

```text
reproducible_description: true
public_runtime_reproduction: false
implementation_disclosed: false
```
