# System Definition

SAEE is treated as:

```text
a frozen empirical phase-space object derived from a constrained computational
evolutionary system exhibiting strong attractor convergence and bounded
diversity
```

The measured object is bounded by:

```text
kernel_modified: false
new_evolution_mechanics: false
observer_feedback_into_kernel: false
core_loop_count: 1
fitness_model: single_unified_fitness
lineage_model: single_lineage_dag
```

The paper does not publish source code, runtime orchestration, kernel
structure, selection procedures, fitness computation, mutation or reproduction
procedures, lineage construction internals, or private architecture details.
