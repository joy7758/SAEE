# Publication Boundary

This public repository is a canonical metadata, landing page, citation, and public abstraction package.

It excludes:

- private core implementation;
- SAEE runtime implementation;
- kernel, selection, mutation, fitness, scoring, and lineage internals;
- production backend implementation;
- local secrets;
- local output artifacts;
- customer data;
- production credentials.

Claims intentionally not made:

- external validation success;
- customer validation;
- production readiness;
- public SDK release;
- benchmark superiority;
- universal law proof.
