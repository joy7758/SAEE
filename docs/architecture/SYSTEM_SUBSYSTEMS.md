# System Subsystems
# 系统子系统

| No. | Subsystem | 中文 | Directory | Purpose |
| --- | --- | --- | --- | --- |
| 1 | Global Sensor Array | 全球感知阵列 | `sensors/` | Observe GitHub, papers, news, regulations, user feedback, and historical failures without unsafe execution. |
| 2 | Trait Extraction Engine | 性状提取引擎 | `trait_extraction/` | Extract reusable traits from external projects, papers, markets, and failure cases without copying code. |
| 3 | Ecological World Model | 生态世界模型 | `world_model/` | Model niches, competition density, resources, risk, and timing. |
| 4 | Counterfactual Future Simulator | 反事实未来模拟器 | `future_simulator/` | Simulate possible future outcomes before execution. |
| 5 | Genome Bank | 基因库 | `genome_bank/` | Store reproducible, mutable, transferable agent structures. |
| 6 | Branching Reproduction Engine | 分支繁殖引擎 | `reproduction/` | Clone, mutate, recombine, and transfer abstract traits. |
| 7 | Development Sandbox | 发育沙盒 | `development_sandbox/` | Develop genomes into repositories, papers, products, demos, or other phenotypes. |
| 8 | Pareto Fitness Arena | 帕累托适应度竞技场 | `fitness_arena/` | Evaluate technical, market, safety, cost, novelty, and evolvability objectives. |
| 9 | Evolutionary Archive and Rollback Immune System | 演化档案与回滚免疫系统 | `evolutionary_archive/`, `immune_system/` | Preserve lineage, failures, rollback points, license boundaries, supply-chain boundaries, and permission boundaries. |
