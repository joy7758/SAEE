# SAEE 示例导航

## SAEE Example Navigation

本目录是产品文档层的示例导航，不复制或移动现有案例。可执行或可验证示例继续保留在仓库根目录 `examples/`、`agent-interface/examples/` 及各能力包的规范位置。

智能体应先读取 `agent-index.json` 和 `llms.txt`，再按目标能力定位示例；不得把合成案例、内部演练或本地 smoke 解释为外部验证、客户采用或生产就绪。

## English technical summary

This directory is a documentation-level pointer. Canonical examples remain in their existing versioned locations; no code or evidence artifact is moved by the product-consolidation layer.
