# Computational Evolution Dynamics

## Definition

SAEE is a computational framework for studying evolutionary dynamics in
multi-agent systems, focusing on regime formation, attractor emergence, and
invariant structural laws arising from selection-driven population processes.

## Scope

Computational Evolution Dynamics studies:

- how computational populations change over long horizons;
- how mutation and selection create observable behavioral regimes;
- how lineage topology records stability, divergence, and collapse;
- how attractor-like states appear in repeated evolutionary trajectories;
- how candidate invariants can be extracted and falsified.

## Core Research Questions

### Evolution State Question

What state is the system operating in?

Candidate states:

- stable regime;
- exploratory regime;
- chaotic regime;
- collapse regime.

### Transition Question

Why does the system move from one state to another?

Candidate causes:

- drift accumulation;
- fitness variance reshaping;
- population bottleneck;
- mutation pressure shift;
- lineage branching density shift.

### Invariant Question

What remains stable across observed change?

Candidate invariants:

- lineage continuity conditions;
- attractor stability conditions;
- selection pressure limits;
- population stability thresholds;
- branching density ranges.

## Evidence Discipline

Every scientific claim must carry a status:

- `local_observation`: directly observed in one local run;
- `candidate_pattern`: repeated or plausible but not yet robust;
- `local_empirical_law`: reproduced across controlled local runs;
- `external_validated_law`: externally validated; currently no SAEE claim has this status;
- `rejected`: contradicted by local evidence.

## Non-Goals

Computational Evolution Dynamics is not:

- a new SAEE kernel;
- an AI audit SDK;
- a generic agent framework;
- a production deployment claim;
- an external validation claim;
- a universal-law claim from one local run.
