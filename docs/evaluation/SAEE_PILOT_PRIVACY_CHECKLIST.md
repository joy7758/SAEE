# SAEE Pilot Privacy and Licensing Checklist v0.1

状态：`not_reviewed`；当前所有检查项均未完成。本清单不声称符合任何法律、监管、许可或安全认证。

在选择数据源前，逐项记录负责人、日期、证据引用和结论：

- [ ] **Data ownership**：数据所有者、提供者和处理授权已书面确认。
- [ ] **Consent requirements**：涉及人员时，已确定是否需要同意以及同意的范围、撤回方式。
- [ ] **Personal data handling**：已识别个人数据，定义最小化、假名化、分离载荷和访问路径。
- [ ] **Sensitive information review**：提示词、路径、URI、凭据、商业信息和安全信息已完成敏感性审查；凭据不得进入数据集。
- [ ] **License and terms**：数据、工具、资源和派生产物的许可及使用条款允许拟议研究用途。
- [ ] **Retention policy**：每类数据的保留期限、保留理由和到期动作已批准。
- [ ] **Deletion process**：可执行删除、撤回和备份清理，并保留最小删除记录。
- [ ] **Access control**：最小权限角色、批准者、存储位置、传输方式和访问复核已固定。
- [ ] **Audit record**：采集、变换、标注、访问、导出、删除和异常事件有可追踪记录。

任一项未完成或结论不清晰时，外部或本地真实运行数据不得进入试点，readiness 必须保持 `NOT_READY`。
