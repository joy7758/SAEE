# SAEE Evidence Acquisition Boundaries v0.1

“This plan specifies future evidence requirements. It does not represent collected evidence, approval, or pilot authorization.”

“该计划定义未来证据需求，不代表已收集证据、已获得批准或已授权试点执行。”

## Fixed current boundaries

```text
current_readiness=NO_GO
evidence_acquisition_started=false
evidence_records_created=false
gaps_addressed=0
pilot_authorized=false
data_collected=false
external_parties_contacted=false
privacy_decisions_created=false

external_validation_completed=false
```

- artifact requirement 不是 artifact record；
- role assignment 不是个人任命或授权；
- verification rule 不是 verification result；
- template 字段不是已填证据；
- validator PASS 只表示计划内部一致；
- 未来 artifact 存在也必须重新运行 readiness review。
