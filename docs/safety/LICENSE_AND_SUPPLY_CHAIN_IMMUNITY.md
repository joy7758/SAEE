# License and Supply-Chain Immunity
# 许可证与供应链免疫

SAEE observes traits, not code.
SAEE 观察性状，不复制代码。

## License Boundary

- Do not copy external source code into genome records.
- Do not import external dependencies without explicit license and supply-chain review.
- Preserve source attribution for public facts, papers, APIs, and datasets.
- Record whether a trait was inferred from public documentation, behavior, benchmark, or user feedback.

## Supply-Chain Boundary

- Unknown install scripts are not executable inputs.
- Unknown repositories are observable sources, not executable dependencies.
- Any future dependency must have a recorded purpose, license, version, integrity surface, and removal plan.
