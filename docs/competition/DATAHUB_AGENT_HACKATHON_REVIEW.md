## 1. 赛事真实性

官方赛事名称为 **DataHub Agent Hackathon**（DataHub 智能体黑客松）。赛事由
DataHub 在 Devpost（开发者赛事平台）承办，当前官方页面可访问，报名与项目提交窗口
仍然开放。

- 官方主页：https://datahub.devpost.com/
- Official Rules（官方规则）：https://datahub.devpost.com/rules
- Schedule（时间表）：https://datahub.devpost.com/details/dates
- Resources（资源页）：https://datahub.devpost.com/resources
- 检索日期：2026-07-18（Asia/Shanghai）

## 3. 参赛资格与地域限制

官方规则要求参赛者达到所在地法定成年年龄，并排除规则列明的若干地域。2026-07-18
页面列出的排除地域包括 Brazil、Crimea、Cuba、Iran、North Korea、Quebec、Russia。
参赛者还需满足雇主、学校或其他组织对参赛与知识产权的规定。

Devpost 报名页提供 `Working solo`（个人参赛）选项，因此允许个人参赛。具体个人资格
属于参赛者本人声明，必须由人类在报名动作前确认；本尽调不代替法律或雇主审查。

来源：

- https://datahub.devpost.com/rules
- https://datahub.devpost.com/register
- 检索日期：2026-07-18

## 4. 赛题

官方提供四个方向：

1. `Agents That Do Real Work`（执行真实工作的智能体）
2. `Metadata-Aware Code Generation & Development`（元数据感知的代码生成与开发）
3. `Production ML Agents`（生产机器学习智能体）
4. `Open / Wildcard`（开放赛题）

SAEE 的候选方向是 `Metadata-Aware Code Generation & Development`，但报名选择不等于
项目已经实现或最终提交。

来源：https://datahub.devpost.com/ ，检索日期：2026-07-18。

## 5. 项目与 DataHub 使用要求

官方规则的关键要求如下：

- `New Projects Only`（仅限新项目）：提交项目必须在本届提交期内开发。
- 若使用提交期之前的代码或资产，必须清楚披露；不得把既有 SAEE 能力包装成本届新成果。
- 必须使用 DataHub Open Source（DataHub 开源版），并至少使用以下一项：
  DataHub MCP Server、Agent Context Kit、DataHub Skills 或 Analytics Agent。
- 项目代码必须放在公众可访问的代码仓库中。
- 仓库顶层必须有清晰可见的 Apache License 2.0（Apache 2.0 许可证）。
- 项目应能由评委方便测试；官方建议提供样例输入和样例输出。

来源：

- https://datahub.devpost.com/rules
- https://datahub.devpost.com/resources
- https://github.com/datahub-project/datahub
- 检索日期：2026-07-18

## 6. 最终提交材料

最终项目提交至少需要：

- Project description（项目说明），说明功能、构建方式与 DataHub 使用方式；
- Public code repository（公开代码仓库）链接；
- 仓库顶层 Apache-2.0 许可证；
- 不超过 3 分钟、公众可访问的 Demo video（演示视频）；
- 可供评委测试的访问方式，或足以复现的本地运行说明；
- 建议附上 sample inputs / outputs（样例输入/输出）；
- 披露任何 submission period（提交期）之前已经存在的代码或资产。

来源：https://datahub.devpost.com/rules ，检索日期：2026-07-18。

## 7. 评审标准

官方评审维度为：

1. `Use of DataHub`（DataHub 使用程度）
2. `Technical Execution`（技术实现）
3. `Originality`（原创性）
4. `Real-World Usefulness`（现实实用性）
5. `Submission Quality`（提交质量）

对 DataHub OSS（开源项目）作出有效贡献可获得 bonus（加分），但不是基础资格要求。

来源：https://datahub.devpost.com/rules ，检索日期：2026-07-18。
