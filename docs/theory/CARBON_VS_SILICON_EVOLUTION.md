# Carbon vs Silicon Evolution
# 碳基演化与硅基演化

## Carbon-Based Evolution

Carbon-based evolution relies on expensive physical reproduction, irreversible death, local memory, slow feedback, and blind search under ecological pressure.
碳基演化依赖昂贵的物理繁殖、不可逆死亡、局部记忆、慢反馈，以及生态压力下的盲搜索。

## Silicon-Amplified Evolution

Silicon-amplified evolution uses cheap branching, parallel simulation, global memory, snapshots, rollback, programmatic evaluation, and verifiable lineage.
硅基放大演化利用低成本分叉、并行模拟、全局记忆、快照、回滚、程序化评估和可验证谱系。

## Design Implication

The system should not imitate biology for style. It should use evolutionary principles where silicon systems can make them safer, faster, more inspectable, and more reusable.
系统不应为了形式而模仿生物。它应使用演化原则，并在硅基系统能够提升安全性、速度、可检查性和复用性的地方放大这些原则。
