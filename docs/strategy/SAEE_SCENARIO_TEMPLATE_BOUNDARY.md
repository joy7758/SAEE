# SAEE Scenario Template Boundary

The Scenario Template Layer only provides domain-specific input templates and
landing-page entry points.

It does not modify:

- SAEE evaluation engine
- runtime
- backend decision logic
- kernel
- fitness logic
- selection logic
- mutation logic
- lineage logic
- scoring mechanism
- API schema
- private core

The layer helps users choose a decision scenario, enter three candidates, create
an evaluation scenario, run the existing SAEE decision loop, and read a decision
report.

It does not claim production readiness, customer validation, external validation,
public SDK release, or private-core availability.
