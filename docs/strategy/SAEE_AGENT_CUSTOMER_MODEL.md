# SAEE Agent Customer Model v0.1

## Primary customer model

SAEE 的主要能力消费模型是 `Autonomous Agent Systems（自主智能体系统）`。

```text
Agent Task Context -> Capability Discovery -> SAEE Invocation
-> Bounded Reliability/Evidence Context -> Agent Decision
-> Human only when consequential authority is required
```

自主智能体需要：

- 可发现的能力身份和稳定契约；
- 判断何时使用、何时弃权的触发规则；
- 可靠性与证据充分性上下文；
- 明确的执行、授权、信任和认证边界。

## Secondary stakeholders

- 人类操作者：保留重大外部动作和责任决定权；
- 开发者：集成并维护稳定调用契约；
- 组织：定义政策、权限和责任边界。

SAEE 不以传统 SaaS 购买者模型作为主要发现路径。人类仍是设计者、操作者和责任引用，但不是智能体能力偏好成立的前置参与者。

## Boundary

主要客户模型是设计假设，不是当前采用证据。它不建立客户、收入、市场接受、外部信任或生产就绪结论。
