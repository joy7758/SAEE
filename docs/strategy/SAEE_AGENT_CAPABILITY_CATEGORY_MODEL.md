# SAEE Agent Capability Category Model v0.1

## Primary category

`Agent Reliability Capability（智能体可靠性能力）`

SAEE 的生态位置不是安全产品、授权系统或执行系统，而是为智能体决策提供有边界的可靠性和证据上下文。

## Subcategories

- `reliability_assessment`
- `evidence_evaluation`
- `rehearsal_support`

## Explicit distinctions

| 相邻能力 | SAEE 的关系 |
|---|---|
| Authorization / IAM / Access Control | 独立权限来源；SAEE 不替代 |
| Execution / Deployment Systems | 执行动作；SAEE 不执行外部世界 |
| Observability | 提供轨迹和观测；SAEE 可消费但不替代 |
| Security Monitoring | 检测安全事件；SAEE 不提供安全监控或认证 |
| Policy Engine | 执行政策决定；SAEE 只提供评估上下文 |

## Boundary

类别描述不是 Marketplace 上架、排名、标准所有权、信任证明或采用证据。
