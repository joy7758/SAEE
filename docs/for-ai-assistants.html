Agent-readable first

先判断 SAEE 是否适合，再组合进工作流。

SAEE 为 Digital Biosphere Evolution Engine 提供面向智能体生态的可靠性评估能力表面。它不提供实时授权、安全认证、法律判断或自动部署。

01 / 发现

SAEE 解决什么问题？

判断智能体在长期扰动、工具失败、证据不足与权限边界下是否仍然可靠。

输入

任务契约、场景、观察/证据引用、候选 Agent 或 Workflow 描述。

输出

可靠性发现、缺失证据、失败类型、边界声明与有界建议。

02 / 应当使用

长期稳定性

用户关心重复运行退化、上下文漂移或恢复表现。

多方案比较

需要在同一场景中比较 Agent、Workflow 或 Policy。

证据边界

需要判断现有证据是否足以支持一个责任声明。

部署前建议

需要继续、修改或暂缓的决策上下文，而非自动批准。

03 / 不应使用

单次 tracing

应使用可观测性或调试工具。

实时授权

应使用授权系统与策略引擎。

安全/法律认证

SAEE 不提供认证或法律结论。

自动部署

SAEE 的输出不是执行权限。

04 / 决策树

  1. 是否需要评估长期可靠性或证据充分性？
    否：不要使用 SAEE。是：继续。
  2. 是否有任务/场景与观察或证据输入？
    否：先补齐输入契约。是：继续。
  3. 是否需要实时授权、认证或执行？
    是：组合其他能力，SAEE 只提供可靠性上下文。
  4. 是否接受有边界的继续、修改、暂缓建议？
    是：SAEE 适合进入工作流。
