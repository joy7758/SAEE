# SAEE Design Partner Anonymous Feedback Template v0.1

状态：`blank_template_only`。该模板没有外部反馈记录，不得填写姓名、邮箱、公司名称、联系方式或其他个人信息。

## Session Boundary

- `anonymous_session_id`：由执行者在获批访谈时生成的无含义本地编号
- `consent_confirmed`：`yes / no`
- `synthetic_material_only`：必须为 `yes`
- `customer_data_received`：必须为 `no`
- `recording_created`：必须为 `no`

## Role

- `role_category`：`evaluation_red_team / governance_consultancy / agent_platform / other_non_identifying`
- `role_context`：最多一句不含个人或组织标识的职责类别描述

## Organization Type

- `organization_type`：`evaluation_lab / consultancy / product_team / research_group / other_non_identifying`
- 不填写实际组织名称、地区或可识别细节。
