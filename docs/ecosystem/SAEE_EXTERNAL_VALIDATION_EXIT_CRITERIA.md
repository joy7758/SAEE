# SAEE External Validation Exit Criteria v0.1

## Completion requirements

一次未来验证只有同时满足以下条件才可结束为 `VALIDATION_SCOPE_COMPLETED`：

1. 至少一个参与者具有当前有效且限范围的授权记录；
2. 授权范围内的测试全部完成；
3. 允许的证据已记录并绑定参与者、版本和范围；
4. 局限性和未测试项已明确记录；
5. 未发生边界违规或终止条件。

## Non-implications

完成不表示市场成功、客户成功、采用、生产就绪、安全认证、法律结论或部署批准。单个参与者的结果不得外推为整个生态兼容。
