# SAEE Ecosystem Validation Evidence Boundary v0.1

## Allowed evidence

- 受控测试结果；
- 兼容性结果；
- 符合 Feedback Schema 的结构化反馈；
- 不含秘密值和客户数据的集成记录。

## Not allowed

- adoption claims；
- customer success claims；
- production reliability claims；
- marketplace ranking claims；
- 私有 prompt、凭据、chain of thought、客户记录或未脱敏生产 trace。

## Interpretation

兼容性 PASS 只回答“在指定版本、模式和受控输入下是否观察到契约匹配”。它不证明参与者采用 SAEE，不证明真实业务可靠性，也不建立信任、认证或部署权力。

## Authority

准备材料、反馈模板和本地测试均不能授权外部联系。任何未来外部 session 必须经过独立、明确、可审计的授权门。
