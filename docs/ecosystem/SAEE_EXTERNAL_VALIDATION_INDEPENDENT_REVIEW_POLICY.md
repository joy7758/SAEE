# SAEE External Validation Independent Review Policy v0.1

## Principle

任何缺口不得仅凭 SAEE 自我声明关闭。`PROPOSED` 不是 `VERIFIED_CLOSED`，模拟证据也不是独立证据。

## Future closure requirements

每项关闭必须同时具备：

1. 可解析的证据引用；
2. 明确的验证方法；
3. 独立审查标记；
4. 与原始 gap ID 的稳定绑定；
5. 不含客户数据、凭据或未授权私有内容。

## Current state

```text
independent_review_completed=false
verified_closed_gap_count=0
```

独立审查完成也不自动授权外部验证执行。
