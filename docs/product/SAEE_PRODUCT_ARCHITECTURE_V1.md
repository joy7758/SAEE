# SAEE 产品架构 v1

## SAEE Product Architecture v1

```text
Agent / Workflow / Policy
          ↓
SAEE Product Surface
          ↓
Digital Biosphere Evolution Engine
   ├── Rehearsal Engine
   ├── Reliability Evaluation
   └── Evidence / Immune Subsystem
          ↓
Capability Runtime
          ↓
MCP / HTTP / Bounded Cloud Mappings
```

SAEE 的核心仍是数字生物圈进化引擎。可靠性评估是面向智能体生态的产品投影；证据和审计属于免疫/证据子系统；MCP、HTTP 与云映射属于运输和生态入口，均不得被解释为授权、信任或生产批准。

## 演化闭环对应

| 产品模块 | 强化的演化子系统 |
|---|---|
| Rehearsal Engine | 反事实模拟、沙盒发育 |
| Reliability Evaluation | 帕累托适应度评估 |
| Evidence / Immune | 演化档案、回滚免疫 |
| Architecture Foundation | 生态世界模型与全局感知语义 |

## English technical summary

The agent-facing reliability surface projects bounded capabilities from the Digital Biosphere Evolution Engine. It does not replace the evolutionary core or expose private execution dependencies.
