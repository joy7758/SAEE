# SAEE GitHub 产品整合演化提案

## English subtitle

SAEE GitHub Product Consolidation Evolution Proposal

## 提案结论

建立统一产品发现层，但不修改 SAEE 的冻结身份：

```text
Theory: Silicon-Amplified Evolutionary Ecology
Engineering Core: Digital Biosphere Evolution Engine
Product Surface: Agent Reliability Evaluation Capability Layer
```

产品表面是 Layer 3 的能力投影，不得反向修改 Layer 1 科学对象或 Layer 2 Meta-Protocol。

## 兼容产品结构

```text
SAEE Digital Biosphere Evolution Engine
        |
        +-- Rehearsal Engine
        +-- Reliability Evaluation
        +-- Evidence / Immune Subsystem
        +-- Capability Runtime
        +-- MCP / HTTP Interfaces
        +-- Cloud Ecosystem Mappings
```

## 阶段

- G1：当前仓库品牌与发现层，允许实施。
- G2：模块注册表与来源映射，允许实施。
- G2.5：逐仓库 Notice 审核，当前 HOLD。
- G3：是否新建公共产品仓库，未授权。

## 禁止动作

- 不把 SAEE 展开为 Smart Agent Execution & Evidence；
- 不删除、归档、改名或重写历史仓库；
- 不把相关研究仓库描述为可重建的端到端生产依赖图；
- 不把可靠性、证据或审计能力提升为项目核心；
- 不执行 GitHub Release、Push、PR 或外部公告。

## English technical summary

This proposal adds a product-facing discovery projection while preserving the frozen scientific identity and engineering core. Historical repositories remain autonomous citation-bearing assets. Module relationships are descriptive and non-executable; they do not form a public dependency graph or production reconstruction map.
