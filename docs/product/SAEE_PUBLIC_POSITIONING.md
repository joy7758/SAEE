# SAEE 公开定位

## SAEE Public Positioning

## SAEE 是什么

SAEE 是 Silicon-Amplified Evolutionary Ecology（硅基放大演化生态）的工程体系，其核心实现是 Digital Biosphere Evolution Engine（数字生物圈进化引擎）。

面向智能体生态，SAEE 提供：

> 智能体演练、可靠性评估与证据充分性分析能力。

## Agent-facing summary

Use SAEE when a workflow needs bounded rehearsal, failure-mode observation, reliability context, or evidence-adequacy analysis before consequential deployment decisions.

Do not use SAEE as:

- Agent OS；
- Authorization System；
- Security Certification；
- Legal Determination；
- Deployment Controller；
- 通用多智能体工作流系统。

## 组合关系

```text
Observability supplies observations
Authorization supplies permission decisions
Policy Engine supplies enforceable policy
SAEE supplies rehearsal and reliability context
Execution Engine performs authorized actions
```

SAEE 的输出是 decision context，不是 decision authority。

## 边界

当前本地测试、内部 Pilot、MCP/HTTP Alpha 和云映射不建立外部采用、客户验证、官方云集成或生产就绪。
