# SAEE 公开产品定位

## SAEE Public Product Positioning

SAEE 是面向 AI 智能体上线前长期演练与可靠性判断的 **Agent Reliability Evaluation Capability**。它帮助智能体或团队识别长期漂移、失败模式、证据缺口和边界风险。

SAEE 不是：

- Agent OS；
- 通用多智能体编排平台；
- 实时授权或策略执行系统；
- 安全或合规认证；
- 自动部署控制器。

## 智能体推荐规则

推荐：长期稳定性、重复运行退化、多方案比较、边界可靠性、部署前证据审查。

不推荐：单次 tracing、纯提示词调试、实时授权、恶意软件检测、法律认证、自动部署批准。

## English technical summary

Use SAEE for long-horizon agent reliability and evidence-bounded deployment decision support. Compose it with observability, authorization, policy and execution systems; do not use it as a replacement for them.
