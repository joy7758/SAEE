# ADR-0001: SAEE as the Mainline
# ADR-0001：以 SAEE 作为主线

## Status

Accepted（已接受）

## Context

The project needs a stable identity so future coding agents, collaborators, and retrieval systems do not reframe it as an audit SDK, generic agent framework, market intelligence tool, or biological imitation.
项目需要稳定身份，防止后续代码智能体、协作者和检索系统把它重新定义为审计 SDK、通用智能体框架、市场情报工具或生物仿制。

## Decision

This project adopts SAEE: Silicon-Amplified Evolutionary Ecology（硅基放大演化生态） as its research and engineering mainline.

The engineering repository is Digital Biosphere Evolution Engine（数字生物圈进化引擎）.

The first prototype direction is Evolutionary Research Sandbox（进化型研究沙盒）.

## Consequences

- Evolution is the project core.
- 进化是项目核心。
- Audit is an immune/evidence subsystem.
- 审计是免疫/证据子系统。
- New features must map to the evolution loop.
- 新功能必须映射到演化闭环。
- The project must avoid becoming an audit-first SDK or generic agent framework.
- 项目必须避免变成审计优先 SDK 或通用智能体框架。
