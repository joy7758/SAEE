# SAEE Agent Reliability Framework Alpha v0.1

> A framework for controlled rehearsal, reliability assessment, and evidence-grounded analysis of autonomous agents.

面向自主智能体的受控演练、可靠性评估和证据化分析框架。

## SAEE 是什么

SAEE 是面向自主智能体的受控演练与可靠性评估框架。它把演练记录、观测、可靠性判断和证据充分性结果组织成有边界、可追溯的分析上下文。工程核心仍是 Digital Biosphere Evolution Engine。

## SAEE 做什么

- Agent rehearsal：在受控、合成环境中演练多步智能体行为；
- Reliability assessment：评估执行、证据和边界可靠性；
- Evidence evaluation：判断固定责任声明是否满足既定证据要求；
- Bounded reports：输出带理由码、缺失项和限制的本地报告。

## SAEE 不做什么

- 不做实时授权执行；
- 不提供认证、法律或合规判断；
- 不批准生产部署；
- 不保证智能体或系统安全；
- 不执行外部世界，也不自动扩大权限。
