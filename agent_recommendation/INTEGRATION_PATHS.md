# SAEE Integration Paths

These paths are product-facing possibilities. They are not implementation
commitments.

| Path | Status | Description | Boundary |
|---|---|---|---|
| Local demo | Available now | Static landing page can call a local `/experiment/run` API when the local backend is running. | Demo only, not production. |
| Internal team evaluation | Prototype only | A team could use sanitized candidate descriptions to discuss deployment decisions. | Requires first-user validation before product claims. |
| Hosted sandbox | Future | A hosted environment for safe agent/workflow comparison. | Not launched, not deployed. |
| Enterprise private deployment | Future | Private deployment for enterprise evaluation workflows. | Not production-ready today. |
