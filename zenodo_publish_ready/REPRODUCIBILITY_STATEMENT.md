# Reproducibility Statement

Status: source-traceability statement, not an executable reproduction package.

## Reproducibility Boundary

This package supports reproducibility at the level of scientific description
and source traceability. It does not provide executable code, runtime
instructions, implementation details, or algorithmic mechanisms.

No commands are provided by this package.

## Verification Scope

A reviewer can verify that this package is self-consistent and
implementation-free by checking:

- all files are documentation or metadata;
- no executable files are included;
- no runtime or kernel logic is described;
- publication-state claims are not embedded in this package; the external
  Zenodo record is the authoritative source for upload, publication, and DOI
  state.

## Non-Reproducibility Boundary

This is not a system reproduction package. It intentionally avoids providing a
system reproducibility attack surface.
