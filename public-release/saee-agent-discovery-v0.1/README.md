# SAEE 公开智能体发现层 v0.1

SAEE 为智能体责任工作流提供机器可验证的证据充分性评估能力。本目录是静态、只读的公开发现包，帮助人和智能体理解 SAEE 是什么、何时使用、何时不使用，以及输入输出边界。

## 建议读取顺序

1. `.well-known/agent-index.json`
2. `capabilities/saee-capability-manifest.v0.1.json`
3. `docs/evidence-adequacy.md`
4. `examples/synthetic-review-example.json`
5. `docs/limitations.md`

## 能力边界

SAEE 是研究原型和证据充分性评估能力。SAEE 不提供安全认证、法律判断、监管合规结论、部署批准或生产治理保证。

本公开包不包含可调用 API、MCP 服务、运行时适配器或客户工作流。公开发现不等于产品发布、外部验证或市场采用。
