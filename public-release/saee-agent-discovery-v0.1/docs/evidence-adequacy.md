# 证据充分性

## 三个不同问题

1. **记录存在：** 某条轨迹或收据是否存在？
2. **记录有效：** 该对象是否满足结构和本地一致性要求？
3. **证据充分：** 这些对象是否满足一项指定责任声明的字段与关系要求？

SAEE 聚焦第三个问题，但不会因为剖面通过就声称现实事件已经得到独立证明。

## 示例解释

若声明是 `RESOURCE_AUTHENTICITY`，固定剖面可以要求请求资源、解析地址、发布者身份、内容摘要和策略决策引用。缺少内容摘要时，结果应指出缺失要求和稳定原因码，而不是给出系统安全结论。

## 评估边界

- `PASS`：固定剖面要求得到满足；
- `FAIL`：至少一个要求缺失或不一致；
- 两者都不是法律、安全、合规或部署结论。

SAEE 是研究原型和证据充分性评估能力。SAEE 不提供安全认证、法律判断、监管合规结论、部署批准或生产治理保证。
