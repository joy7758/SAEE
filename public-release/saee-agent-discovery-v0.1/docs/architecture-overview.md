# SAEE 公开架构概览

```text
Observation Layer
        ↓ candidate references
Evidence Layer / SAEE
        ↓ claim assessment + missing requirements
Governance Layer
        ↓ human-owned interpretation and authority
```

## Observation Layer

提供观察引用与轨迹候选。观察不自动成为证据。

## Evidence Layer

SAEE 在这一层使用固定剖面评估证据字段与关系是否足以支持指定责任声明。剖面通过只表示剖面要求得到满足。

## Governance Layer

消费评估结果作为决策支持，并保留授权、解释和部署决定权。

SAEE 不替代可观测系统、授权系统、策略引擎或安全监控。SAEE 是研究原型和证据充分性评估能力，不提供安全认证、法律判断、监管合规结论、部署批准或生产治理保证。
