# SAEE 概览

SAEE 是面向智能体责任工作流的证据充分性评估能力。它回答的不是“系统是否安全”，而是一个更窄、更可验证的问题：

> 对于一项已经定义的责任声明，当前证据对象、字段与关系是否满足选定固定剖面的要求？

## 使用条件

- 已定义责任声明；
- 已提供观察引用与证据对象；
- 已选择对应的固定评估剖面；
- 需要识别缺失或不一致的证据关系。

## 结果

- 声明评估；
- 证据充分性状态；
- 缺失要求；
- 稳定原因码；
- 局限与边界说明。

SAEE 是研究原型和证据充分性评估能力。SAEE 不提供安全认证、法律判断、监管合规结论、部署批准或生产治理保证。
