# SAEE Cloud Entry Package 快速开始

## 前提

- 从 SAEE 仓库根目录运行；
- 使用仓库现有 Python 环境；
- 不需要百度凭据、不访问网络、不安装依赖；
- 只使用包内合成 Demo，不提交客户或个人数据。

## 1. 一键验收

```bash
python3 scripts/saee_cloud_entry_package_smoke.py
```

## 2. 智能客服退款 Agent

```bash
python3 scripts/saee_baidu_readiness.py evaluate-agent-run \
  --input cloud-entry-package/demo/customer-service-refund/request.json
```

预期：`readiness=conditional`、`score=75`、缺少
`HUMAN_APPROVAL`。这不是退款或上线授权。

## 3. 代码发布 Agent

```bash
python3 scripts/saee_baidu_readiness.py evaluate-agent-run \
  --input cloud-entry-package/demo/coding-agent-release/request.json
```

预期：`readiness=replan`、`score=50`、缺少
`ROLLBACK_PLAN` 与 `HUMAN_APPROVAL`。部署不会执行。

## 4. 单独评估证据包

```bash
python3 scripts/saee_baidu_readiness.py evaluate-evidence \
  --input cloud-entry-package/demo/evaluate-evidence/request.json
```

预期：`evidence_quality=PARTIAL`、`coverage_score=67`。

## 5. MCP 发现

```bash
python3 scripts/saee_qianfan_readiness_mcp_stdio.py
```

通过 JSON-RPC `initialize`、`notifications/initialized`、`tools/list` 后，
工具列表必须严格等于：

```text
saee.evaluate_agent_run
saee.evaluate_evidence
```

## 分数解释

`score` 与 `coverage_score` 是必需证据覆盖率，不是 Agent 可靠概率、安全概率、
认证结果或部署批准。
