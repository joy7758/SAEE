# SAEE AI 智能体上线前可靠性评估服务

## 这项服务解决什么问题

AI 智能体、Agent 工作流或自动化方案准备上线时，团队经常知道“功能能跑”，却不确定失败时能否定位、证据是否够用、哪些环节需要人工确认。SAEE 通过一次范围明确的人工评估，帮助您在正式部署前把这些问题看清楚。

## 适合哪些客户

- 正在建设 AI 智能体、Agent SaaS 或企业内部智能体的团队。
- 需要比较多个工作流或方案，但缺少统一评估依据的团队。
- 希望在上线、版本升级或回归测试前检查运行证据的团队。
- 使用阿里云百炼或其他 Agent 构建平台，并能导出经授权、脱敏运行材料的团队。

## 您需要提供什么

1. 一个 AI Agent 工作流说明。
2. 一个需要评估的具体业务场景。
3. 经负责人授权并完成脱敏的运行记录或事件轨迹。
4. 已有测试结果、回滚方案、权限边界或人工确认记录；没有的部分可以标记为缺失。

请勿提交密码、密钥、身份证件、银行卡、未脱敏个人信息或未经授权的客户数据。

## 我们如何评估

1. 确认服务范围与材料边界。
2. 检查运行证据是否覆盖关键事件、异常和外部影响。
3. 标记证据缺口、失败定位缺口与恢复准备缺口。
4. 给出 `CONTINUE`、`REPLAN`、`HUMAN_REVIEW_REQUIRED` 或 `STOP` 的有界建议。
5. 交付结果并提供一次结果解读。

## 您会收到什么

- 结构化 JSON 评估结果，便于 AI Agent 或工程工具读取。
- 中文可读评估报告，便于产品、研发和负责人共同审阅。
- 缺失证据清单，明确还需要补充什么。
- 有边界的改进建议，帮助安排下一轮测试或人工复核。
- 限制与适用范围说明，避免把评估结果误当作部署授权。

## 为什么容易被理解和复用

SAEE 的输入、输出、建议标签和不适用场景都有明确契约。客户可以先用中文报告做决策，也可以让编码智能体、检索智能体或工作流系统读取 JSON 结果，继续组织后续测试和人工审批。

## 服务边界

- 本服务是上线前可靠性评估，不是安全认证或合规认证。
- 本服务不承诺绝对安全、零故障或业务结果。
- 本服务不自动部署、不操作客户生产系统、不扩大权限。
- 本服务不代表已完成阿里云百炼官方技术集成。
- 是否上线、发布或执行高影响动作，仍由客户负责人独立授权。
