- 服务类型：阿里云云市场服务类商品
- 服务范围：1 个 AI Agent 工作流 + 1 个评估场景
- 交付方式：人工评估，交付 JSON 与中文报告
- 当前边界：不自动部署，不操作客户系统，不替代安全或合规认证

## 1. 购买后如何开始

### 第一步：进入交付中心

购买后，请在阿里云云市场“已购买的服务”中进入交付中心。交付中心会显示本次服务的流程、材料和确认节点。

### 第二步：提交需求

请填写一个明确的 Agent 工作流和一个具体场景，并说明您最关心的问题，例如：证据是否充分、失败是否可定位、是否具备回滚准备。

### 第三步：准备材料

- 工作流或智能体功能说明。
- 经负责人授权并完成脱敏的运行记录。
- 已有测试结果、回滚方案、权限边界和人工批准记录。
- 不存在的材料请直接标记“缺失”，无需编造。

### 数据安全提示

请勿提交密码、密钥、身份证件、银行卡信息、未脱敏个人信息或未经授权的客户数据。SAEE 只评估经授权、脱敏的材料。

## 2. 评估流程与交付结果

### 评估流程

1. 确认范围：核对一个工作流、一个场景和材料边界。
2. 证据检查：检查关键事件、异常、外部影响和人工授权证据。
3. 缺口分析：标记证据缺口、失败定位缺口与恢复准备缺口。
4. 结果生成：输出结构化 JSON 和中文报告。
5. 结果解读：说明结论、限制和建议的下一步。

### 交付内容

- 结构化 JSON 评估结果。
- 中文可读评估报告。
- 缺失证据清单。
- 有边界的改进建议。
- 适用范围与限制说明。

### 建议标签

- CONTINUE：在当前证据边界内可以继续下一步评估。
- REPLAN：建议调整方案或补充关键证据后再评估。
- HUMAN_REVIEW_REQUIRED：需要负责人或专业人员复核。
- STOP：当前证据不足，建议停止高影响动作。

## 3. 如何验收与获得支持

### 验收检查

- 报告是否对应约定的工作流与场景。
- JSON 与中文报告中的结论是否一致。
- 缺失证据是否明确列出。
- 建议是否包含适用范围和限制。
- 客户可以在交付中心确认、留言或提出一次结果解释问题。

### 售后支持范围

工作日 09:00-18:00（北京时间）提供材料准备、评估结果解读和交付问题答疑。具体交付时间、质保、退款与验收条款以最终商品规格和协议为准。

### 不包含的服务

- 不代替安全认证、合规认证或法律意见。
- 不自动部署、不代运维、不操作客户生产系统。
- 不处理未经授权或未脱敏的数据。
- 不承诺绝对安全、零故障或特定商业结果。
- 不声称与任何云平台完成官方技术集成或获得平台背书。

### 联系与问题处理

请优先通过阿里云云市场订单、交付中心留言或店铺客服渠道联系。涉及材料变更时，请在交付中心保留清晰记录，便于双方复核。
