# Raw Notes

These are paraphrased notes from public sources. No long copyrighted text is
copied.

## S001 LangSmith Platform

LangSmith markets itself as a framework-agnostic agent engineering platform
that covers observing, evaluating, and deploying agents.

## S002 LangSmith Pricing

LangSmith publishes free/developer, paid team, and enterprise tiers. Enterprise
mentions self-hosted and hybrid deployment options, custom SSO/RBAC, support
SLA, and custom seats/workspaces.

## S003 Arize Agent Evaluation

Arize frames agent evaluation as harder than final-output evaluation because
agents can take unexpected paths. It emphasizes tool use, planning, reflection,
and agent-specific diagnostics.

## S004 Arize Pricing

Arize points to Phoenix as open-source and local-first for tracing,
evaluation, experimentation, and prompt iteration, with Arize AX as the
commercial path.

## S005 Braintrust Evaluate

Braintrust frames systematic evaluation as quality measurement, regression
detection before users, and confidence that AI systems are improving.

## S006 Braintrust Pricing

Braintrust pricing exposes processed data, scores, retention, RBAC, support,
and enterprise hosted/on-prem deployment axes.

## S007 Humanloop Evaluations

Humanloop emphasizes evaluation before deployment decisions, evaluator suites,
benchmarking, root-cause analysis, CI/CD regression detection, and SME feedback.

## S008 Humanloop Pricing

Humanloop exposes a free trial shape and enterprise private deployment,
SSO/SAML, RBAC, SLA, and VPC deployment add-on language.

## S009 Langfuse Self-Hosted Pricing

Langfuse offers self-hosted OSS with observability, evaluation, prompt
management, datasets, deployment docs, and enterprise support add-ons.

## S010 W&B Weave Agents

W&B Weave frames agent evaluation around traces, scorers, guardrails, registry,
and development/production iteration for multi-step agentic systems.

## S011 Galileo Agent Evaluation

Galileo describes agent-specific metrics for tool selection, action
advancement, agent flow, action completion, CI/CD, post-incident evals, and
runtime protection.

## S012 Galileo Pricing

Galileo enterprise pricing emphasizes hosted, VPC, or on-prem deployment,
security, support, real-time guardrails, and dedicated inference.

## S013 Patronus Agent Development

Patronus describes tracking agent dialogues, generating performance data, and
iterative feedback for agent evaluation.

## S014 Patronus AWS Marketplace

The AWS Marketplace page frames Patronus as automated LLM evaluation and
security for scoring performance, adversarial tests, benchmarking, and safer AI
deployment.
