# Commercial Relevance Notes

Review candidates only. Do not execute, approve, or convert any item into
roadmap work without human review.

## Signals Supporting SAEE's First Wedge

- Public tools are increasingly explicit about agent evaluation, not just LLM
  output evaluation.
- Agent observability pages emphasize tool use, planning, multi-step actions,
  regressions, and failure modes.
- Several competitors frame evaluation as pre-deployment or production safety
  infrastructure.
- Enterprise packages repeatedly mention private deployment, VPC, on-prem,
  SSO/RBAC, retention, and support.

## Signals Weakening SAEE's First Wedge

- The adjacent market is crowded around observability, tracing, prompt evals,
  and guardrails.
- Many tools already combine evals with monitoring and production feedback.
- SAEE's distinction must remain narrow and legible: long-term competitive
  stability and deployment recommendation, not generic observability.

## Competitor Language SAEE Should Learn From

- "agent evaluation"
- "observability"
- "failure modes"
- "regression before production"
- "private deployment"
- "guardrails"
- "CI/CD evaluation"
- "enterprise support"

## Pricing / Packaging Lessons

- Common axes: seats, traces, scores, processed data, retention, hosted/private
  deployment, enterprise support, and custom security.
- Free or low-friction entry tiers are common.
- Enterprise private deployment appears as a premium packaging axis.

## Private Deployment Lessons

- Private, VPC, on-prem, hybrid, self-hosted, SSO, RBAC, and SLA language is
  common in enterprise-facing AI evaluation products.
- SAEE can learn from this language, but must not imply public core release or
  production readiness without separate approval.

## What Should Remain Unchanged

- SAEE should not claim to be a generic tracing tool.
- SAEE should not claim to replace production monitoring.
- SAEE should not expose private core.
- SAEE should not claim production readiness.
- SAEE should keep external AI assistant testing manual unless explicitly
  approved otherwise.
