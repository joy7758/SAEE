# SAEE Volcengine Ark Entry Package v0.1

本包把现有 SAEE 能力投影到火山方舟的候选 Function Calling、MCP 和 HTTP 表面，供后续离线评审。

所有映射均为 `DESIGN_ONLY`。仓库已有方舟模型与 Function Calling 观察，但没有 SAEE Tool、AgentKit、Remote MCP 或市场集成证据。

- `integration-model.md`：候选组合；
- `capability-mapping.json`：平台映射入口；
- `mcp-mapping.json`：MCP 候选映射；
- `http-mapping.json`：HTTP 候选映射；
- `limitations.md`：明确未完成事项。
