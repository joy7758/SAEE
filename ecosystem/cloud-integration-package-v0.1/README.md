# SAEE Cloud Integration Package v0.1

本目录是引用型生态进入准备包。它让云平台或 Agent 工具链理解 SAEE 的能力、MCP/HTTP 候选入口和真值边界，不复制 Capability Runtime 或评估实现。

- `capability-card.json`：机器可读能力卡；
- `integration-model.md`：平台组合关系；
- `mcp-definition.json`：现有 MCP 入口引用；
- `http-definition.json`：现有 HTTP 入口引用；
- `limitations.md`：未完成事项。
