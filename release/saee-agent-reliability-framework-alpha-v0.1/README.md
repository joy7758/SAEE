# SAEE Agent Reliability Framework Alpha v0.1

> A framework for controlled rehearsal, reliability assessment, and evidence-grounded analysis of autonomous agents.

面向自主智能体的受控演练、可靠性评估和证据化分析框架。

本目录是本地、引用型 Alpha 定位包。它索引仓库中的规范来源，不复制实现，也不代表已创建 GitHub Release。

## 能力

- 在受控合成环境中组织智能体演练；
- 对固定契约下的智能体运行记录进行可靠性评估；
- 对责任声明进行证据充分性评估；
- 生成有边界、可追溯的本地报告。

## 入口

- 机器能力清单：`capabilities.json`
- 架构：`architecture.md`
- 快速开始：`quick-start.md`
- 演示索引：`examples/README.md`
- 限制：`limitations.md`
