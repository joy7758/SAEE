# 本地快速开始

从仓库根目录运行：

```bash
python3 scripts/saee_capability_runtime_demo.py
python3 scripts/saee_capability_runtime_smoke.py
python3 scripts/saee_alpha_positioning_release_smoke.py
```

智能体应先读取 `capabilities.json`，再按 `canonical_ref` 解析能力边界。完整入口见 `docs/public/SAEE_AGENT_QUICK_START.md` 与 `examples/public-demo/README.md`。

所有操作均限定于本地、合成、非生产范围。
