# Supplementary material

This archive accompanies:

> Evidence Presence Is Not Semantic Support: An Impossibility Result for
> AI-Agent Readiness Claims

It contains the synthetic 16-pair dataset, data dictionary, frozen expected
results, canonical result manifest, pinned environment description,
retrospective analysis plan, reproduction instructions, deterministic runner,
and offline artifact verifier described in the manuscript.

Run from the extracted archive root:

```bash
python3 experiment/verify_artifact.py
```

The expected success marker is:

```text
SAEE_RECONSTRUCTABILITY_ADEQUACY_ARTIFACT: PASS
```

The archive contains no passwords, private author profiles, residential
addresses, customer data, production data, or executable third-party
dependencies. Its cases are authored synthetic construct-validation fixtures,
not an operational sample or a production-readiness benchmark.
