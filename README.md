# SAEE

SAEE is an AI agent long-term stability evaluation and decision infrastructure system.

SAEE is Silicon-Amplified Evolutionary Ecology. Its engineering core is the Digital Biosphere Evolution Engine. This public repository is a public-safe canonical and abstraction layer for discovery, citation, and evaluation framing.

## What SAEE Is

- AI agent long-term stability evaluation and deployment decision infrastructure.
- A public product surface for long-horizon evaluation, multi-agent comparison, failure-mode analysis, survival ranking, and deploy / hold / retest decision support.
- A citable and agent-readable external authority surface for GitHub, Zenodo, landing pages, and AI retrieval systems.

## What SAEE Is NOT

- Not a tracing tool.
- Not a prompt debugger.
- Not a production monitoring dashboard.
- Not an audit-first SDK.
- Not a generic multi-agent workflow framework.
- Not a public release of the private evolution kernel, runtime, scoring, selection, mutation, or lineage implementation.
- Not a claim of production readiness, customer validation, external validation success, or public SDK release.

## Repository Contents

- `docs/`: static public landing pages and canonical metadata.
- `public_abstraction/`: toy public abstraction examples only.
- `zenodo_publish_ready/`: definition-only scientific package; no executable implementation.
- `CITATION.cff`: GitHub citation metadata.
- `.zenodo.json`: Zenodo GitHub-release metadata draft.
- `agent-index.json`: compact agent-readable index.
- `llms.txt`: compact LLM entrypoint.

## Boundary

This repository intentionally excludes private implementation internals. It does not include SAEE runtime code, kernel code, fitness logic, selection logic, mutation logic, lineage internals, production backend code, secrets, local outputs, or proprietary commercial implementation payloads.
